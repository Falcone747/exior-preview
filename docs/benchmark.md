# Benchmark — niveau et mécanismes

Observation Playwright du 19.11.2026. Modèles rhétoriques seulement. Aucune phrase reprise. UiPath `/product/agentic-automation` répond 404 : la page plateforme a été lue à la place. ServiceNow et Make répondent 403 ou un interstitiel : rien n’est inventé pour les remplacer. Zapier charge un mur avant le corps : seule la navigation accessible est notée.

## UiPath — plateforme d’orchestration

1. Le titre part du résultat d’entreprise, pas du modèle.
2. L’argument suivant sépare l’essai d’IA et le résultat obtenu.
3. L’automation est présentée comme insuffisante sans une couche d’orchestration.
4. La plateforme est découpée en trois couches : coordonner, exécuter, faire respecter la confiance.
5. Chaque couche a un lieu : où le travail est réparti, où il est fait, où la confiance est tenue.
6. Le vocabulaire reste opérationnel : orchestration, exécution, contrôle.
7. Peu de slogans, beaucoup de structure.
8. Le CTA ramène à la plateforme, pas à une fonction isolée.
9. La preuve annoncée est l’architecture, pas un pourcentage.
10. À retenir : nommer la couche manquante, puis montrer où le travail passe.

## Workato — agents et orchestration

1. La promesse est un délai de mise en œuvre, opposé à un projet long.
2. Les agents sont nommés par fonction d’entreprise, pas par technologie.
3. Une page liste des agents, l’autre la plateforme qui les gouverne.
4. Le contrôle est un plan : passerelle, sécurité, exécution.
5. Une comparaison binaire sert à distinguer agent libre et système gouverné.
6. Le CTA est une démonstration, pas une liste de qualités.
7. L’écosystème vient après le mécanisme.
8. À retenir : un agent sans plan de contrôle n’est pas l’offre.

## Relevance AI

1. Le résultat nommé est un flux de revenu, pas « l’IA ».
2. L’opposition est nette : des agents qui travaillent, contre un système qui assemble agents, outils et personnes.
3. Le coût d’usage est posé comme problème avant la solution.
4. Un premier cas d’usage concret ouvre, le reste de la plateforme suit.
5. La supervision est une condition : rien ne tourne sans regard.
6. Les benchmarks sont présentés comme un réglage, pas comme un score client.
7. Les connexions à des applications sont un composant, pas une décoration.
8. À retenir : l’unité de vente est l’assemblage, pas l’agent seul.

## Dust

1. Le cadre est la collaboration entre personnes et agents, pas l’agent isolé.
2. Le contexte d’entreprise est la matière du travail.
3. Un seul système concentre le travail d’IA.
4. Le travail change de main entre une personne et un agent.
5. Le contrôle des données est une section, pas une note.
6. La valeur est décrite comme cumulative entre équipes.
7. À retenir : dire qui tient le contexte, et qui peut arrêter l’action.

## Anthropic — agents efficaces

1. Le texte définit l’agent avant d’en vanter l’usage.
2. Il dit aussi quand ne pas utiliser d’agent.
3. Les briques sont séparées : flux de travail, outils, agent.
4. Les motifs se combinent : orchestrateur, sous-agents, évaluation, revue humaine.
5. Le niveau est celui d’une note d’ingénierie, phrases courtes, termes stables.
6. À retenir pour EXIOR : orchestrateur, agents spécialisés, outils, garde-fous, validation humaine, évaluation. Aucune phrase de cette page n’est reprise.

## Linear et Cursor

1. Une phrase dit le produit. L’objet à l’écran porte la suite.
2. La navigation est courte. Un bouton d’action.
3. Les sections sont un titre, une idée, un objet.
4. Pas d’adjectif à la place d’un mécanisme.
5. Le fond est sombre, l’accent est rare, le rythme est large.
6. À retenir : si la phrase ne nomme pas un composant, elle sort.
