# PAGE 3 — COMMENT ÇA MARCHE `/comment-ca-marche`

**SEO title** : Comment EXIOR transforme le fonctionnement d'une entreprise

## HERO

# Du travail fragmenté à une organisation coordonnée.

Une entreprise ne fonctionne pas logiciel par logiciel. Elle fonctionne à travers des processus qui traversent les équipes, les données et les outils.

**EXIOR conçoit la structure qui permet de les piloter comme un ensemble.**

## LE PRINCIPE

### Un événement. Un processus. Un résultat.

**Événement** — email reçu, document ajouté, échéance atteinte, information mise à jour ou demande d'un collaborateur.

**Compréhension** — le système identifie le contexte, les règles et les données nécessaires, dans les limites des accès définis.

**Coordination** — les tâches sont attribuées aux logiciels, agents ou personnes les mieux placés pour les exécuter.

**Exécution** — les actions autorisées sont réalisées, les validations sensibles sont demandées, les exceptions sont traitées.

**Traçabilité** — chaque étape importante peut être enregistrée et suivie par les utilisateurs habilités.

## LES SIX COUCHES DE L'ARCHITECTURE

1. **Systèmes existants** : comptabilité, CRM, ERP, messagerie, dossiers, banques, logiciels métier.
2. **Référentiels et données** : dossiers, clients, fournisseurs, contrats, procédures, règles.
3. **Orchestration** : événements, planifications, états des workflows, reprises sur erreur.
4. **Agents spécialisés** : analyse, recherche, préparation, contrôle et actions permises.
5. **Contrôle humain** : authentification, droits, validations, alertes, audit.
6. **Espace EXIOR envisagé** : interface unifiée permettant de suivre les opérations, interroger les données autorisées et demander des actions.

*Les composants décrivent l'architecture cible. Leur implémentation est une prestation distincte.*

## EXEMPLE

### Une facture fournisseur : au-delà de la lecture automatique

**Sans coordination** : un document est extrait, puis un collaborateur doit choisir le bon dossier, vérifier le contrat, contrôler les doublons, préparer la saisie, suivre les exceptions et s'assurer que le traitement est achevé.

**Avec une architecture EXIOR déployée et intégrée** : le processus peut identifier son contexte, contrôler les règles, préparer les opérations dans le logiciel autorisé, soumettre les cas sensibles à validation, relancer le suivi et documenter l'état final.

Le gain potentiel porte sur **la chaîne de coordination**, pas seulement sur l'extraction de trois champs d'un document.
