# Écrire le copy

Utilise ce que tu as observé avec REA. Ne parte pas d’un modèle Accenture ou d’un template.

## Règles

- Une phrase, un fait.
- Titre = changement d’état, pas une liste de livrables.
- Pas de superlatif. Pas de négation en titre.
- Pas de jargon : pas de « levier », « synergie », « transformation » vide.
- Meridian fictif. Aucun client réel inventé.

## Structure

- Hero : une promesse, le prix, le délai, un bouton.
- Schéma : nœuds reliés, pas de cartes vides.
- Offre : 990 €, 7 jours, conception seulement.
- FAQ : objections réelles, réponses courtes.

## Sortie

Le copy est écrit dans la page. Pas de fichier séparé.
