# Écrire le copy

- Une phrase, un fait.
- Présent actif.
- Le titre vend un changement d’état, pas une liste.
- Pas de superlatif. Pas de négation en titre.
- Pas de jargon Accenture.
- Ton d’un associé qui a vu le goulot.

Ordre : promesse, preuve (le schéma), objection, offre, bouton.

Lis à voix haute. Si une phrase pourrait être chez eux, réécris-la.
