# Observer avec REA

Ne construis rien tant que cette étape n’est pas faite.

## Setup

```bash
npx rea-agents@latest setup --client cursor
```

Redémarre Cursor. Un seul canal.

## Ce que tu observes

Choisis une page premium réelle (entrepreneurs.com, Linear, Stripe, ou une page citée dans le brief). Avec REA :

- Structure : ordre des sections, largeur des blocs, placement du CTA.
- Copy : longueur des titres, nombre de faits par phrase, ton.
- UX : hiérarchie visuelle, contraste, rythme, formulaire.

## Ce que tu ne fais pas

Tu ne copies ni phrase, ni chiffre, ni visage, ni client.

## Sortie

Écris 5 lignes max : ce que tu retiens pour la structure, le copy et l’UX. Ensuite seulement, passe à `/definir-le-design-system`.
