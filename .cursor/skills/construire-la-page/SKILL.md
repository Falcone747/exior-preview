# Construire la page

1. Lis `AGENTS.md` et `DESIGN.md`.
2. Lis `index.html` et `commander/`.
3. Si REA est branché, observe exior.io, entrepreneurs.com, zapier.com, accenture.com. Note dans `docs/grammaire.md` l’ordre, l’échelle, le bouton, les cartes. Aucune phrase copiée.
4. Tokens et composants d’abord : bouton, carte, schéma, barre.
5. Home dans l’ordre de `DESIGN.md`. Puis `commander/`. Puis les pages intérieures, mêmes tokens.
6. `python3 -m http.server 8080`. Regarde 1280 et 390. Corrige avant de dire que c’est fait.
7. Délègue à `critique-visuelle` avant le commit.
8. Commit sur `main`. Message : ce qui a changé.
