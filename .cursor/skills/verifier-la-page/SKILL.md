# Vérifier la page

Ne dis pas que c’est fait tant que chaque ligne n’est pas vraie.

## Offre

- 990 €, 7 jours ouvrés, conception seulement.
- Meridian marqué fictif.
- Bouton « Obtenir mon architecture » partout.
- Aucun client, chiffre ou visage inventé.

## Contraste

- Texte normal ≥ 4.5:1.
- Contrôles ≥ 3:1.
- Secondaire vérifié.

## Formulaire

- Labels visibles.
- 2 à 4 champs. Pas de téléphone.
- Ligne sur les données sous le bouton.
- Focus clavier visible.

## Typo

- Corps ≥ 16 px mobile.
- Hiérarchie visible (taille + graisse).

## Performance

- LCP ≤ 2.5 s. Pas d’opacité 0 sur le hero.
- CLS ≤ 0.1.
- Images WebP < 200 Ko.

## Preuve visuelle

- Capture 1280 px : hero lisible, schéma large, bouton visible.
- Capture 390 px : pas de débordement, bouton accessible sans zoom.
- Colle les chemins des captures dans ta réponse.

## Légal

- Liens mentions, confidentialité, CGV dans le pied.
- Pages intactes.

## Schema

- JSON-LD présent et conforme à ce qui est affiché.

## Sortie

Une ligne par défaut. Si rien, « rien à corriger ».
